# 真实米粿调用安全说明

## 先理解两个事实

1. 默认模拟模式不会访问米粿，不会上传图片，也不会扣真实积分。
2. 一旦启用米粿，草稿和阶段结果会通过网络发送给米粿，并可能产生实际积分消耗。

P0 仅限内部、单租户、权利清晰的测试。它不是已经获得多租户 SaaS、代调用或转售授权的生产平台。

## 两条链路、四道付费安全门

两条真实生成链路相互隔离，各自必须同时满足两项条件：

- 经典勾线/上色/光影：`ALLOW_REAL_PROVIDER=true` 且 `P0_INTERNAL_USE_ACK=true`；
- 3.0 / StoryArk 分镜成稿：`ALLOW_STORYARK_GENERATION=true` 且 `STORYARK_INTERNAL_USE_ACK=true`。

对应链路缺少任何一道门，程序都会拒绝该链路的付费调用。凭据齐全并不等于已经授权调用；管理员的“检查两路 MCP”只读取工具清单和项目列表，不创建绘图任务，因此不要求打开付费门。

## 推荐：密钥只放在工作区外

不要把真实凭据写进项目 `.env`。建议在项目之外保存一个仅供本机读取的文本文件，例如：

```text
MIGUO_ACCOUNT_ID=你的账号标识
MIGUO_API_TOKEN=你的令牌
```

启动脚本也接受以下 JSON 形式：

```json
{
  "MIGUO_ACCOUNT_ID": "你的账号标识",
  "MIGUO_API_TOKEN": "你的令牌"
}
```

也兼容现有的中文标签格式：

```text
我的账号: 你的账号标识
API KEY: 你的令牌
接口地址: https://factory.miguocomics.com/api/mcp/v1
```

如果文件提供接口地址，启动脚本只接受 `https://factory.miguocomics.com`，不会把凭据发送到其他主机。

该文件不能放在项目目录或其子目录。启动脚本只把值注入本次运行进程，不会把它复制到工程中，也不会打印值。

可以先只验证外置文件和双安全门，不启动服务，也不访问米粿：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\start-local.ps1 `
  -Provider miguo `
  -CredentialFile "D:\安全位置\miguo-credentials.txt" `
  -AllowRealProvider `
  -AcknowledgeInternalP0 `
  -ValidateOnly
```

## 真实模式启动命令

确认账号、素材权利和积分风险后，在项目目录运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\start-local.ps1 `
  -Provider miguo `
  -CredentialFile "D:\安全位置\miguo-credentials.txt" `
  -AllowRealProvider `
  -AcknowledgeInternalP0 `
  -OpenBrowser
```

也可以预先在当前 PowerShell 进程中设置 `MIGUO_ACCOUNT_ID` 和 `MIGUO_API_TOKEN`，然后省略 `-CredentialFile`。不要在共享终端、录屏或会保存命令历史的场景中把 Token 直接写在命令行。

启动后先点击“检查两路 MCP”。这会访问米粿并读取能力清单及 StoryArk 项目列表，但不会创建绘图任务。确认经典链路三项核心能力与 3.0 三项能力都正常，并确认 StoryArk 至少有一个项目后，再分别从 1 格、1 个候选开始验证。当前本地 `start-local.ps1` 的真实模式参数只开放经典链路；3.0 门应仅由服务器受限配置显式管理。

## 每次真实验证前检查

- 素材归属和商业使用权限已确认；
- 米粿账号允许本次内部 P0 使用；
- 已了解上传、留存和删除安排；
- 当前批次没有客户隐私或不应出网的信息；
- 只选择计划中的少量格子，先单格后批量；
- 已记录调用前的实际积分余额；
- 确认每格每阶段最多两次尝试，不通过重复建批次绕过；
- 有人负责处理超时、未知结果和重复扣费疑问。

## 运行中的安全规则

- 不把 Token 粘贴到网页；工作台没有前端密钥输入框；
- 不在截图中展示终端环境变量或凭据文件内容；
- 不把完整请求头加入日志；
- 不因界面超时立即重复提交。先记录发生时间、格号、阶段和任务状态；
- 供应商返回的结果会立即转存到本地资产目录，不把临时 URL 当作永久资产；
- 界面显示的是估算积分，最终以米粿账户记录为准。

## 结束后

按 `Ctrl+C` 停止程序。启动脚本会恢复启动前的进程环境变量；凭据文件仍留在原来的工作区外位置。

然后执行：

```powershell
pnpm scan:secrets
```

如检查发现疑似真实凭据，不要把扫描输出公开发送。先停止共享或提交，确认位置，移除泄露内容并轮换 Token。

## 不推荐的做法

- 把真实 Token 写进 `.env.example`、README 或源码；
- 把凭据文件复制到 `samples`、`data`、`docs` 或桌面截图；
- 用 `VITE_`、`NEXT_PUBLIC_` 等前端变量保存 Token；
- 把真实模式作为默认启动模式；
- 在授权、成本和数据留存尚未确认时开放给外部用户；
- 为了省事关闭 URL 白名单、HTTPS 检查或任一付费安全门。
