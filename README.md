# 米粿Studio · 漫画 P0 工作台

这是一个内部可行性验证工具，用来回答一个具体问题：一批已经切好的漫画草稿，能否稳定地经过“勾线 → 底色 → 光影 → 人工选定 → 固定排版”，并且降低实际返工时间。

当前实现状态、已验证内容和真实 12 格测试前仍需准备的材料，见 [P0 交付与下一检查点](docs/P0-交付与下一检查点.md)。

正式前端是 [public/index.html](public/index.html)：单文件、HTML/CSS/JS 全内联、无构建步骤、无 CDN 依赖。左侧将两套能力分为平级入口：漫画创作工作流以“每列一张草稿、每列纵向四阶段”呈现草稿 → 线稿 → 上色 → 光影；分镜到成稿工作流以简洁的“参考图 → 分镜 → 成稿”三步列呈现。内部创作理解仍由服务端自动完成，不占用客户界面中的独立步骤。前端直接使用 P0 的批次、panel、run、素材版本和提升接口；不是 `/jobs` 占位接口。

同源访问 <http://127.0.0.1:4317> 是推荐方式。也可以双击 `public/index.html`，页面会从 `file://` 安全连接本机 `127.0.0.1:4317`；浏览器不保存或传递米粿账号与 Token。

它默认使用模拟处理器，不连接米粿，也不会扣除真实积分。界面里的“积分账本”在模拟模式下只是测试数字。后端已接入相互隔离的“米粿经典”和“米粿 3.0 / StoryArk”两条 MCP 连接；能力、门控与当前限制见 [双米粿 MCP 接入说明](docs/双米粿MCP接入说明.md)。

## 最安全的启动方式

在本目录打开 PowerShell，运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\start-local.ps1 -OpenBrowser
```

首次运行会安装所需组件，然后启动本地工作台。浏览器没有自动打开时，请访问：

<http://127.0.0.1:4317>

关闭运行窗口或按 `Ctrl+C` 即可停止。数据会保存在本机 `data` 文件夹，下次启动仍可继续查看。

> 默认模式始终是 `mock`：不上传草稿、不访问米粿、不消耗真实积分。即使工作目录里误放了 `.env`，启动脚本也会在模拟模式中关闭真实调用。

## 线上 MVP

个人服务器上的受保护 MVP 已部署到：

<https://leoandfriends.cool/miguo-studio/>

线上使用应用内账号登录，支持成员自助注册。密码只保存为加盐 `scrypt` 哈希，会话使用 HttpOnly、Secure、SameSite Cookie，写操作还需要 CSRF 令牌。成员只能看到自己的批次，平台管理员可查看历史与全部批次；真实米粿调用仅允许管理员发起。线上实例使用独立 Node 24、systemd 守护、Nginx HTTPS 反向代理和 `/var/lib/miguo-studio` 持久化目录。

线上后端的默认供应商仍为 Mock；管理员可在界面显式选择真实生产。两条米粿连接的凭据仅保存在服务器受保护环境中，经典勾线/上色/光影与 StoryArk 3.0 的真实能力都只向平台管理员开放，并继续受各自两道安全门保护。烟测证据见 [Factory 经典链路真实烟测记录](docs/Factory经典链路真实烟测记录.md) 与 [StoryArk 真实烟测记录](docs/StoryArk-真实烟测记录.md)，发布结构、服务检查、更新与回滚说明见 [MVP 部署与运维](docs/MVP部署与运维.md)。

## 直接查看带演示内容的前端

如果想先看完整界面而不准备图片，可运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\start-frontend-preview.ps1 -OpenBrowser
```

脚本会在工作区的 `work/manga-frontend-demo` 中生成一组本地演示画面，包含已完成、待审、失败和上游版本改变等代表状态。它强制使用演示模式，不读取米粿凭据，也不会产生真实积分。

## 第一次验证建议

1. 导入少量已经切好的单格 PNG、JPEG 或 WebP 图片；首次上传会自动建立并持久化一个 P0 批次。
2. 保持设置中的“使用 P0 模拟处理器”开启，顶部应显示 `P0 Mock`。
3. 对单格执行“生成线稿”，或使用带可执行数量徽标的批量按钮。
4. 线稿完成后上色自动解锁；上色完成后光影自动解锁。
5. 对结果点击“标记不满意”，填写一句修改意见并重做；新上游结果会自动作废该格下游结果。
6. 刷新页面，确认棋盘顺序、已完成素材、失败和进行中任务均从服务端恢复。
7. 如某一步失败，只重试失败项；不要重新运行已经通过的格子。

为了贴合这个轻量工作台的“一键继续”体验，生成成功的候选会自动提升为当前版本；后端仍保留旧版本、依赖谱系与审批记录。P0 的固定 2×2 导出能力仍在后端，但尚未放进这个棋盘界面。

模拟结果只验证任务编排、版本、恢复、导出和操作体验，不代表米粿的真实画面质量。

完整步骤与判定标准见 [P0 操作与验收手册](docs/P0-操作与验收手册.md)。

## 开启任一路真实米粿前

真实调用会上传素材，并可能消耗米粿积分。经典流水线与 3.0 / StoryArk 各有两道独立安全门；部署凭据本身不会打开付费生成：

- 经典流水线：`ALLOW_REAL_PROVIDER=true` 与 `P0_INTERNAL_USE_ACK=true`；
- 3.0 / StoryArk：`ALLOW_STORYARK_GENERATION=true` 与 `STORYARK_INTERNAL_USE_ACK=true`；
- Studio 分镜理解 Agent：服务端设置 `STUDIO_MAIN_MODEL_BASE_URL`、`STUDIO_MAIN_MODEL_API_KEY`，并显式开启 `STUDIO_MAIN_MODEL_ENABLED=true`。批量理解固定使用 `gpt-5.6-luna`，单格生成或再次生成前固定使用 `gpt-5.6-terra`；浏览器不能指定模型。Agent 会理解完整分镜与人设参考之间的角色、部件和道具关系，并为真实图像模型准备创作上下文；Agent 未就绪或分析不完整时不能绕过分析直接提交付费生成。
- 分镜成稿的供应商与模型完全由服务端管理：`STUDIO_STORYBOARD_RENDER_PROVIDER` 决定内部渲染路线，客户浏览器不再显示或提交供应商、模型型号与项目 ID。默认内部路线需同时开启 `STUDIO_IMAGE_MODEL_ENABLED=true`、`ALLOW_STUDIO_IMAGE_GENERATION=true`、`STUDIO_IMAGE_INTERNAL_USE_ACK=true`。新任务保存完整成稿并归一方向、画布尺寸、色彩空间和 PNG 编码；旧任务仍按自身冻结路线恢复。
- 凭据只通过工作区外的文件、当前进程环境变量或服务器受限环境文件提供；
- 米粿账号、素材权利和内部 P0 使用范围均已确认。

管理员的“检查两路 MCP”只执行能力清单和 StoryArk 项目读取，不要求打开付费门。不要把 API Token 写进 README、源码、截图、测试样例、聊天记录或提交记录。具体门控和外置凭据说明见 [真实米粿调用安全说明](docs/真实米粿调用安全说明.md)。

## 当前可以验证什么

- 批量导入单格草稿；
- 勾线、底色、光影三个受控阶段；
- 独立的“分镜到成稿工作流”：批量新增分镜、逐列关联人设参考图、用 Luna/Terra 理解角色与要素，再由 Nano Banana 2 生成完整候选成稿；新任务直接采用供应商原生画面并归一到分镜画布尺寸，旧版选择性合成任务仍可只读恢复；
- 分镜任务批量选择并设置截止日期；提报时冻结当前采用的图片版本，同一组织的关联账号可在“团队提报”中只读查看，后续重生成不会静默替换已提报版本；
- 每格每阶段生成不可变候选，并由当前工作台自动提升最新成功结果；
- 旧版本保留、恢复，以及上游改变后的下游过期提示；
- 单项失败重试、任务重启恢复与积分/耗时记录；
- 刷新恢复、列顺序持久化、带意见重做和下游失效；
- 注册、登录、退出、会话保护和成员批次隔离；
- 后端固定 2×2 PNG 页面和 JSON 排版清单（当前棋盘尚未暴露导出按钮）。

它不是完整漫画生产平台。小说导入、人物时期造型、自动拆解脚本、气泡文字、局部圈选返工、专业条漫排版、完整审阅/接手流和模型管理后台仍不属于当前 P0；3.0 当前支持列式分镜到成稿，不包含局部重绘参数。当前只提前落地了单组织 membership、截止日期与不可变提报快照；共享积分、组织项目、邀请、指派、认领和多组织切换仍按 [B 端组织协作设计](docs/B端组织协作设计.md) 分阶段实现，阶段范围见 [P0 与后续阶段边界](docs/P0-P1-边界.md)。

管理后台 P1 的产品、指标、组织积分账本、主模型安全配置和实施顺序见 [管理后台产品与技术方案](docs/管理后台产品与技术方案.md)。可双击打开 [管理后台交互原型](prototypes/miguo-studio-admin.html) 查看总览、组织、账号、积分、任务、模型与审计页面；原型只含虚构演示数据，不连接后端，也不会保存 API Key。

## 常用命令

```powershell
# 默认安全启动：模拟处理，不扣真实积分
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\start-local.ps1 -OpenBrowser

# 检查程序文件
pnpm check

# 运行自动测试
pnpm test

# 检查交付目录中是否误放了密钥
pnpm scan:secrets
```

如需重新安装依赖，可给启动脚本增加 `-Install`。不要删除 `data` 目录来解决普通故障；其中保存了批次、候选版本和导出记录。

## 本地文件说明

- `data/assets`：导入图与各阶段候选；
- `data/exports`：2×2 PNG 页面与对应 JSON 清单；
- `data/p0.sqlite`：批次、版本、任务、审批和成本记录；
- `samples/private`：仅供本机放置有权使用的验证素材，默认不会进入版本控制；
- `.env.example`：配置字段示例，不应填写真实密钥后提交。

如果启动失败，请先阅读 [P0 操作与验收手册中的故障处理](docs/P0-操作与验收手册.md#常见问题)，并保留界面提示与发生时间；不要把 Token 一同复制给他人。
